# Supported versions

Choose the add-on that matches both your Minecraft version and mod loader. This branch provides `0.4.0.2602002` for Minecraft 26.2, NeoForge `[26.2.0.45-beta,26.2.1)`, and exactly Iron Age Furniture `0.4.0.2602002`.

The add-on accepts the stable Minecraft 26.2 BOP build `26.1.2.0.40` and newer builds below `26.3`, with GlitchCore `[26.2.0.0.0,26.3)` and TerraBlender `[26.2.0.0.1,26.3)`. The Minecraft target shown on each jar's download page matters; a similar numeric version is not enough. Both stable BOP and the newer `26.2.0.0.28` build passed packaged client, server and furniture-upgrade checks.

All required mods must be installed together. If a newer release changes its compatibility range, use the requirements shown on that release's download page and in Minecraft's Mods screen.

Phase 4 releases also require GlitchCore `26.3.0.0.5` or newer and TerraBlender `26.3.0.0.9` or newer for Minecraft 26.3. Supporting stable BOP does not remove those library requirements.

## Understanding the add-on version

The first three numbers are the add-on's feature version. The final number identifies the Minecraft target and loader:

- `260300` means Minecraft 26.3.
- The final `2` means NeoForge.

For example, `0.3.0.2603002` is feature release 0.3.0 for Minecraft 26.3 on NeoForge.
